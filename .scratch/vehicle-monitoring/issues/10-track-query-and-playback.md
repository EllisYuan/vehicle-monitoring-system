# 10: 单车轨迹查询与回放

Status: open
Labels: ready-for-agent
Type: task
Blocked by: 08

## What to build

按单车、单次最长 24 小时的 gps_time 范围查询轨迹，允许跨日，受 30 天保留期与数据权限约束，原始 track_point 不被修改。查询先按无效定位与相邻有效点间隔 >30 秒分段，再对每段做 Douglas-Peucker 抽稀，米制容差默认 10m 起调整；保留首尾、分段边界与重要事件关联位置，展示点总数 ≤2000。必要点仍超限时返回缩小范围提示，不静默截断。提供浏览器回放：播放、暂停、拖动时间轴、1/2/4/8 倍速；断点显示缺失且不跨段插值；不提供原始轨迹批量导出，实时尾迹同样不跨断点伪连。权限按车辆访问权与事件车队权限校验，车队长只可查询授权车辆。本票自带必要的 API、页面、审计与测试。

## Spec coverage

主：AC22、AC23（US 46–51），见 [spec](../spec.md#可检查验收场景)。
复验：AC06 数据范围（跨队轨迹不可读）；AC14 无效点断点；AC13 补传点只进历史不回退实时。
重要事件关联点的保留依赖 12 与 27 的事件数据落地；本票先交付无事件点路径，待其完成后按 [12](12-overspeed-rules-and-alarm-lifecycle.md) 的 Answer 复验，27 汇总执行。

## Acceptance criteria

- [ ] 单车辆与 ≤24 小时范围校验，跨日允许，超范围返回明确错误
- [ ] 真实 MySQL 数据查询展示点 ≤2000，原始轨迹行未被修改
- [ ] 无效定位与 >30 秒缺口形成分段，回放不跨段连线
- [ ] 抽稀保留首尾与分段边界；已存在的重要事件点输入不会被丢弃，可用受控样例验证，真实报警数据在 12/27 复验
- [ ] 必要点超限返回缩小范围提示，不截断
- [ ] 浏览器回放验证播放/暂停/拖动/1/2/4/8 倍速，时间轴与车辆位置一致
- [ ] 车队长跨队查询被服务端拒绝，页面无原始轨迹导出入口
- [ ] 查询与越权尝试产生审计记录

## Scope boundaries

不实现原始轨迹批量导出、异步导出与里程/油耗统计；不改动 track_point 结构与 07 的分区语义；不实现底图接入与真实天地图验证（属 26）；不生成报警事件点，仅消费其数据。后票不代办本票测试。

## Validation

以真实 MySQL 8.4 与浏览器验证：可由模拟终端经 TCP 上报或单独生成跨日、含无效点、缺口与高密度点的单车数据，记录命令、环境与版本、时间范围、返回点数与分段数，回放操作步骤及截图证据。地图底图失败不影响列表结论但须注明。每条记录状态为通过、失败、未执行或仅静态检查，不得预填通过。
