# 03: 车辆、终端档案与历史绑定

Status: resolved
Labels: ready-for-agent
Type: task
Blocked by: 02

## What to build

复用 02 的 fleet 与授权能力，补齐所需车队档案字段，交付 vehicle、terminal 基础档案与 terminal_vehicle_binding、vehicle_fleet_history：车队编号/名称/启停，车辆车牌与所属车队，终端预登记与启停，页面到数据库贯通。任一时点车辆与终端一对一；绑定使用 effective_from/effective_to 左闭右开区间，变更不倒填，由数据库唯一约束与事务/行锁保证并发下不形成重叠当前关系。停用档案保留历史，不物理删除有引用的记录。换绑保留旧区间与历史，车辆转队写 vehicle_fleet_history 并留审计。档案维护仅管理员可用，监控员全企业只读，车队长仅授权车队只读；服务端权限同 02。实际 TCP 换绑后的会话处置不在本票，由 06 与 09 复验。

## Acceptance criteria

- [x] 页面可维护车队、车辆、终端档案并完成预登记、启停
- [x] 真实 MySQL 下并发绑定同终端/同车辆不产生重叠当前关系
- [x] 绑定区间左闭右开，生效区间可追溯且不倒填
- [x] 换绑前后历史区间保留，停用档案不物理删除
- [x] 车辆转队写 vehicle_fleet_history 并留审计记录
- [x] 未启用或已被占用的终端不能绑定，拒绝原因可解释
- [x] 车队长只读且仅见授权车队车辆，跨队请求被拒
