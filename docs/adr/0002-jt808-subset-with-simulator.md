# 以自研 JT/T 808 子集与模拟终端验证监控链路

用户在 Q4 与 Q12 确认：采用 Netty 处理 TCP 通信，自行实现 JT/T 808-2019 必要消息的 codec 与注册鉴权等会话流程，由独立模拟器作为主要开发与验收数据来源。选择这条路线是为了让毕业设计能够展示并重复验证报文解析到监控业务的完整链路，同时把开发范围限制在本期功能所需的协议子集；真实终端为后续可选验证。

本期不承诺旧版协议兼容、JT/T 809 级联或 JT/T 1078 视频。具体消息清单与异常处理边界待后续对齐，codec 验证需包含独立报文样例；模拟器和服务端互测通过不等于完整标准符合性或真实设备互通验证。
