# 单实例模块化单体承载业务与终端接入

用户在 Q13 确认采用模块化单体：一个 Spring Boot 进程提供 HTTP API、WebSocket 与 Netty TCP 接入，一套 Vue 前端，模拟器独立运行。针对单企业、100 辆模拟车辆、单人约 10 周的毕业设计，选择集中部署以控制联调和运维成本，代码内按业务职责保留模块边界；网络处理与数据库操作使用不同执行线程。

本期仅部署一个后端应用实例，通过 Linux 单机 Docker Compose 管理后端、前端/Nginx 和 MySQL 等服务；不承担集群、高可用或微服务拆分。Maven 模块划分、缓存用途、消息处理与一致性细节待后续确认，单实例验收结果不能外推为多实例能力。
